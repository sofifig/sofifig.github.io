# COMO SE HIZO CADA RECORTE
#
# El recorte se hace en dos pasos, porque la lamina traia margen
# blanco y ademas varias imagenes traian mas blanco adentro:
#
#   1. se recorta a la caja real del contenido de la lamina, que deja
#      fuera el pie con los nombres y el logo TUM
#   2. sobre esa imagen se mide cuanto blanco queda pegado a cada
#      borde y se vuelve a recortar, esta vez por pixel, dejando seis
#      pixeles sin cortar. Ese margen hace falta: el borde suavizado
#      de una linea o de una letra se mide como blanco, y cortando al
#      ras el dibujo queda mordido (le paso al cauce, se comio la
#      linea negra de arriba y la base del 06.2023)
#
# Las dos series que se hojean (04-estructura-2 a -6, y todo el
# 06-detalle) comparten recorte: se les quita solo el blanco que
# sobra en TODAS. Si se recortara cada una a su dibujo, la base y la
# cubierta terminada saldrian del mismo tamaño y se perderia la
# sensacion de que la estructura crece al pasar de una a otra.
#
# Maquetas: se arman las dos paginas A5 lado a lado y se recorta al
# area de las fotos, mas el mismo afeitado por pixel.
#
